# Life

אפליקציית אנדרואיד אחת לתזונה, אימוני כוח וריצה. ממשק בעברית, עיצוב כהה.

נבנתה מאיחוד של שלוש אפליקציות:
- **MacroFactor** (הבסיס): יומן אכילה, ברקוד, צילום AI, משקל, הוצאה קלורית אדפטיבית, צ׳ק-אין שבועי.
- **Lift**: רוטינות, אימון פעיל עם טיימר מנוחה, יעדי התקדמות, שיאים, מאמן כוח, דילואוד, סופרסטים, סטטיסטיקה.
- **Stride**: ריצות מ-Garmin דרך intervals.icu, VDOT, אזורי קצב, תוכנית שבועית מבוססת מחקר, מרוצים ותחזיות.

## הרכב גוף

- **התקדמות ← תזונה ומשקל ← הרכב גוף**: תמונה מקדימה ותמונה מהצד; Gemini מעריך אחוז שומן (עם טווח) ורמת שריריות, והאפליקציה מחשבת מסת שומן, מסה רזה והערכת מסת שריר לפי המשקל. מהסריקה השנייה התמונות הקודמות נשלחות להשוואה, ויש גרף אחוז שומן ותצוגת לפני/אחרי.
- התמונות נשמרות רק בטלפון (`body/` בתיקיית המסמכים של האפליקציה); הגיבוי כולל את המספרים בלבד (`docs`, אוסף `body_scans`). הלוגיקה: `src/body/model.ts` (נבדקת ב-`npm run test:body`), `src/body/analysis.ts`, `app/body.tsx`.

## יומן, תכנון ויעדים

- **אימון ← יומן**: יומן משותף לכוח וריצה, סינון, היסטוריה ותכנון לארבעת השבועות הבאים.
- **תכנון שבועי / שיבוץ**: רוטינות כוח וריצות ביום קבוע בכל שבוע, או אימון חד־פעמי. הזזה וביטול של אימון בודד אינם משנים את שאר הסדרה. תוכנית הריצה המפורטת מחליפה ריצה שבועית כללית באותו יום.
- **התקדמות**: סיכום שבועי של תכנון מול ביצוע, יעדי אימונים ותזונה, ומגמות בארבעת השבועות המלאים האחרונים. נתוני תזונה חסרים מוצגים בנפרד; ההשוואה ליעדים משתמשת ביעדים הנוכחיים.
- **הגדרות ← תזכורות**: שעת תזכורת לאימוני היום ועד שלוש שעות לרישום ארוחות. ההפעלה מבקשת הרשאת התראות בטלפון. תזכורות אימונים מתוכננות ל־28 ימים ומתרעננות בפתיחה, בחזרה לאפליקציה ובשינוי התכנון. תזכורות הארוחות חוזרות מדי יום.

התכנון והתזכורות נשמרים בטבלת המסמכים ונכללים בגיבוי ובשחזור.

## איך זה בנוי

| חלק | איפה |
|---|---|
| ממשק | Expo 57 + React Native + expo-router, `app/` |
| תזונה ומשקל | SQLite (טבלאות MacroFactor), `src/db`, `src/lib` |
| כוח | `src/strength` — הלוגיקה של Lift, נשמרת כמסמכי JSON בטבלת `docs` |
| ריצה | `src/run` — המדע והמתכנן של Stride, רצים בטלפון; ריצות נמשכות מ-intervals.icu |
| AI | Gemini (`src/lib/gemini.ts`) עם מפתח של המשתמש, שמור ב-SecureStore |
| גיבוי | Supabase של המשתמש (`src/lib/cloud.ts`): טבלת `backups`, שורה אחת למשתמש, RLS |

אין שרת משלנו. כל המפתחות (Gemini, intervals.icu) מוזנים באפליקציה ונשמרים בטלפון בלבד.

## פקודות

```bash
npm install --legacy-peer-deps
npx tsc --noEmit                                         # בדיקת טיפוסים
npm run test:planning                                    # בדיקות תכנון, סיכומים ותזכורות
npx eas-cli build -p android --profile preview           # APK חדש (כשמשנים חבילות נייטיב)
npx eas-cli update --channel production --environment production --platform android -m "תיאור" # עדכון לטלפון בלי התקנה מחדש
```
